What we sell

Two fixed-fee offers for organizations of any size — small, mid, and large. Healthcare and other regulated industries are examples of where this work shows up, not the brand.

Offers

Engagements are scoped to one of these outcomes. Automation in the Halo Switch toolkit is how delivery stays license-mapped and auditable.

  • Google Workspace → Microsoft 365

    Migrate from Google Workspace into Microsoft 365 with a clear cutover plan: identity, mail, and collaboration foundations aligned to the licenses you own — dry-runnable before production.

  • New Microsoft 365 tenant configuration

    Configure a new Microsoft 365 tenant from the ground up — domains, SKUs, admin roles, identity baselines, and the first wave of groups and device readiness so the tenant is usable on day one.

How the work gets done

These are delivery capabilities inside migration and tenant engagements — not separate product names on the shelf.

  • Dynamic Groups

    Create and audit Entra dynamic membership rules (department, country, job title patterns) so access stays aligned as the organization changes.

    Typical license: Entra ID P1+

  • Lifecycle (joiner / mover / leaver)

    Scripted onboarding, role-change mover, and offboarding runbooks — user attributes, group deltas, sign-in block, session revoke, and optional license reclaim.

    Typical license: Entra ID Free+ (P1+ when paired with dynamic groups)

  • License groups & audit

    License-driven group maintenance: attribute gap audit and SKU-linked static group membership so entitlements match the people who need them.

    Typical license: Entra ID Free+ (P1+ when feeding dynamic groups)

  • Intune / device foundations

    Intune discovery and tenant foundation scaffolding — compliance and configuration baselines, enrollment patterns, and Windows device readiness as licensed.

    Typical license: Microsoft Intune / M365 E3+

  • SSO & Conditional Access readiness

    Enterprise application / service principal inventory and Conditional Access readiness notes. Deeper CA work continues beyond the current scaffold.

    Typical license: Entra ID P1 for many Conditional Access features
